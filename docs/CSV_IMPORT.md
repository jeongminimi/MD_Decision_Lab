# 판매 CSV 입력 안내

대시보드에서 **상품 CSV 가져오기**와 **판매 CSV 가져오기**를 각각 사용합니다. 상품 파일을 먼저 넣으면 신규 SKU를 등록하고 현재 재고·원가 정보를 갱신할 수 있습니다. 기존 SKU는 업데이트하며, 파일에 없는 상품이나 판매 이력은 삭제하지 않습니다.

## 상품 CSV

| 컬럼 | 필수 | 의미 |
|---|---|---|
| `sku` | 예 | 고유 상품 코드 |
| `name` | 예 | 상품명 |
| `category` | 예 | 분류, 비우면 `기타` |
| `stock_on_hand` | 예 | 현재 판매 가능 재고 |
| `inbound_units` | 예 | 입고 예정 수량 |
| `lead_time_days` | 예 | 발주 후 입고까지 예상 일수 |
| `target_cover_days` | 예 | 운영상 목표 재고 보유일 |
| `unit_price` | 예 | 현재 판매 단가 |
| `unit_cost` | 예 | 상품 원가 |

상품 샘플은 `sample_data/products_import_template.csv`에 있습니다.

## 일별 판매 CSV

판매 파일의 SKU는 상품 목록에 먼저 등록돼 있어야 합니다.

| 컬럼 | 필수 | 의미 |
|---|---|---|
| `sku` | 예 | 상품에 등록된 SKU (예: `MD-001`) |
| `sale_date` | 예 | 판매일, `YYYY-MM-DD` 형식 |
| `units_sold` | 예 | 해당 날짜의 판매 수량, 0 이상의 정수 |
| `revenue` | 예 | 해당 날짜의 매출 금액, 0 이상 |
| `gross_margin` | 아니요 | 해당 날짜의 매출총이익. 비워두면 상품 원가로 추정 |

UTF-8 또는 CP949 인코딩을 지원합니다. 같은 SKU와 날짜를 다시 올리면 해당 날짜 기록을 추가 누적하지 않고 새 값으로 교체합니다. 실패 행은 최대 8개까지 안내합니다. 실제 회사 파일을 사용할 때는 고객 이름, 연락처 등 개인 정보 열을 포함하지 마세요.

샘플은 `sample_data/sales_import_template.csv`에 있습니다. 샘플을 그대로 올리면 샘플 날짜의 해당 SKU 판매 기록이 교체됩니다.
